# autumnAlarmClock

The Autumn Alarm clock has a Orange Asthetic that means to exude a fall theme. 

It has 4 switches that are configured to allow a user to set the time, change the current time, and set a alarm. These 3 primary functions can be seen coded in the firmware folder. 

The CAD is to be printed in 2 parts, the top plate, and the actual container. 

The PCB is based apon the AGENT Aurum theme and has the periodic symbol of Gold!
